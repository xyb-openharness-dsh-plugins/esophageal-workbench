### 定义

食管癌是发生在食管黏膜上皮的恶性肿瘤。这个病的第一道分岔不是「几期」，而是两个更基础的问题：病理类型是鳞癌还是腺癌，病变在食管的哪一段。本台把这两项作为建档的双主键，不合并成「食管癌」一个档案。

病理类型上，食管鳞状细胞癌与食管腺癌是两条不同的病程与治疗路径，指南按类型分别列条目；本台要求先选类型再建档。部位分段分为颈段、胸上段、胸中段、胸下段、食管胃结合部（EGJ），分段由内镜与影像报告给出，本台只抄原文，不按距门齿距离自行推算。EGJ 病变用 Siewert 分型记录（医生给出），本台只留记录位，不自动计算、不据此推荐术式。分期用 TNM；本项目未取得 AJCC 原件，版本未核实，报告上的 T/N/M 只抄不判。本台不把「鳞癌 / 腺癌」或「哪一段」解释成严重或好治——类型与分段只决定指南里有哪些条目，不决定你的结局。

### 目前治疗全景概要

按病期与线序列出指南里出现过的手段类别。这是「世界上大致有哪些办法」的地图，不是给你排的先后顺序，也不含剂量、疗程与适用条件——那些必须由医生按你的病理类型、分段、分期与身体情况决定。

- **局限期 / 可切除（以手术为主）**：手术——食管切除 + 淋巴结清扫 + 消化道重建是这一路径的核心，具体术式、切口与重建方式由外科团队按病变位置决定。／围手术期治疗——新辅助放化疗、新辅助化疗、新辅助免疫治疗在指南与 2026 年登记研究中都有条目，本台只记录「做过哪一类、起止日期」。／早期、局限于黏膜的表浅病变——指南列有内镜下切除（EMR / ESD）这一类别，是否适用由内镜与病理判断，本台不替选。／术后辅助——按病理分期、切缘与淋巴结情况，指南列有观察、辅助化疗或辅助放化疗等条目。
- **根治性放化疗 + 免疫巩固（不手术路径）**：根治性同步放化疗（dCRT）——放疗与化疗同期进行，作为不做手术时的根治性路径；本项目 2026 登记里「放疗 / 放化疗」主题近似命中 45 条。／免疫巩固——dCRT 结束后进入免疫治疗维持阶段，指南与登记研究中都单列这一阶段，本台只记录起止与复查节点，不评价疗效。／路径切换——从手术路径转到 dCRT、或从 dCRT 转到系统治疗，旧路径记录保留、不覆盖，这是本台的结构要求，不是治疗建议。
- **晚期 / 复发 / 转移**：系统治疗——化疗、HER2 靶向（腺癌语境）、免疫检查点抑制剂、CLDN18.2 等靶点在指南与登记研究中出现，具体药是否国内获批、是否在医保内需单独核实。／姑息放疗——用于局部症状控制的放疗条目在指南里列出，本台只记录「做过没有、什么时候、几次」。／营养与进食通路支持——经口调整、支架、鼻饲、胃造瘘、空肠造瘘都是记录位，本台不推荐品牌、不建议时机、不做分诊。／临床研究——指南把「参加登记良好的临床试验」列为一项正式选项，不是最后手段。
- **贯穿全程的两件事**：吞咽与营养记录——吞咽自查六档（普食 / 软食 / 半流 / 流食 / 水呛 / 完全梗阻）固定标注「自查，不是医生评估」；体重与白蛋白双序列只画趋势，不判读。／随访与第二原发监测——胃镜 + 影像的复查节点按医生安排记录；鳞癌烟酒人群的头颈 / 肺监测只记录「医生安排了什么」，不给风险提示。

以上是文献与指南里列出的手段，按病期与线序排列，**不代表任何一项适合你**。选哪一个，这一句需要问你的医生。

简体中文 · EsopPal Esophageal Cancer Workbench

小咽宝（EsopPal，占位名）是面向食管鳞癌与食管胃结合部腺癌患者及照护者的 DSH Desktop 本机优先工作台。它围绕"病理类型与部位分段决定治疗路径"这一第一决策点，记录吞咽分级变化、进食通路切换与放化疗疗程。医疗内容只用于资料整理和就诊沟通，不替代医生诊断或治疗意见。

## 当前状态（v0.1.0，如实）

- **原型**：`prototypes/v0.2/` 为定稿快照（G2），`file://` 可只读打开，改动请另开新版本目录。
- **开发版**：`public/`（原生 ESM，无构建）+ `dsh/`（本机 sqlite、`/api/bootstrap`）+ `lib/`（面板参数唯一来源）。
  `npm start -- --workspace <目录>` 起服务；资料目录必须由你明确选择（主目录 / 桌面 / 下载根目录 / tmp 会被拒绝）。
- **数据层**：`schema/0001_initial.sql`（25 表 / 174 列）+ `0002_section_titles.sql`（2 列 ALTER），
  哈希在 `schema/freeze-contract.md`；改结构只能新增迁移。演示数据唯一来源是 `demo/build-demo-data.mjs`。
- **DSH Desktop 接入**：`lib/client.js` 与 `dsh/index.js` 已按家族标准分栏写好（`businessSide:'left'`、0.65、
  `customFrame:false`），但**尚未实机安装验证**；相关合同见 `docs/02-DSH-CONTRACT.md`、`docs/09-WORKBENCH-STATUS.md`。

## 产品范围（一期规划）

- 病理与分段（专属主线）：鳞癌/腺癌分开建档；颈/胸上/胸中/胸下/食管胃结合部分段（EGJ 含 Siewert 分型记录位）。
- 治疗路径三选一：手术路径 / 根治性放化疗（dCRT）+ 免疫巩固 / 系统治疗；路径切换保留旧记录不覆盖。
- 吞咽与进食通路（专属模块）：吞咽自查六档序列（普食→完全梗阻，固定"自查，不是医生评估"标注）、通路档案（经口/支架/鼻饲/胃造瘘/空肠造瘘，起止日期）、扩张记录与误吸事件。
- 检查与指标：体重 + 白蛋白双序列（四癌种中营养不良负担最重）；SCC-Ag 仅鳞癌档案显示。
- 复诊准备：胃镜 + 影像随访节点；第二原发监测安排记录（鳞癌烟酒人群，只记医生安排）。

## 数据与能力边界

- 患者数据必须存入用户明确选择的资料目录；导入文件在本机处理，识别字段先作为候选内容展示，用户核对后才写入病情记录。
- 2026 临床试验资料包按家族统一方法学采集（资料包在样板癌种链路确认后补充）；登记不证明有效、安全或开放入组。
- 临床试验搜索结果是查找线索，不代表符合入组条件；试验状态和入排标准应向研究中心核实。
- 工作台不提供诊断、分期判读、疗效评价或处置建议；用户看法与担心按"一条信息"记录，标注"不是医生结论"。
- 原型中全部数据为虚构演示数据，不是真实病例。

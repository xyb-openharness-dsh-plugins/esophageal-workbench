简体中文 · EsopPal Esophageal Cancer Workbench

小咽宝（EsopPal，占位名）是面向食管鳞癌与食管胃结合部腺癌患者及照护者的 DSH Desktop 本机优先工作台。它围绕"病理类型与部位分段决定治疗路径"这一第一决策点，记录吞咽分级变化、进食通路切换与放化疗疗程。医疗内容只用于资料整理和就诊沟通，不替代医生诊断或治疗意见。

## 当前状态（v0.1.0，如实）

- **设计审定阶段**：已交付 SPEC v0.1（`docs/SPEC.md`）、HTML 交互 demo（`prototypes/v0.1/`）、用户研究假设文档；G1/G2 审定进行中，未逐页签认。
- 结直肠癌为家族样板癌种，走完整链路（SPEC → demo → 2026 临床数据 → SQLite）；本癌种先到 SPEC 草案，样板确认后复用骨架批量产出。

- 数据结构（`schema/`）在 G3 通过前不会建表。

## 产品范围（一期规划）

- 病理与分段（专属主线）：鳞癌/腺癌分开建档；颈/胸上/胸中/胸下/食管胃结合部分段（EGJ 含 Siewert 分型记录位）。
- 治疗路径三选一：手术路径 / 根治性放化疗（dCRT）+ 免疫巩固 / 系统治疗；路径切换保留旧记录不覆盖。
- 吞咽与进食通路（专属模块）：吞咽自查六档序列（普食→完全梗阻，固定"自查，不是医生评估"标注）、通路档案（经口/支架/鼻饲/胃造瘘/空肠造瘘，起止日期）、扩张记录与误吸事件。
- 检查与指标：体重 + 白蛋白双序列（四癌种中营养不良负担最重）；SCC-Ag 仅鳞癌档案显示。
- 复诊准备：胃镜 + 影像随访节点；第二原发监测安排记录（鳞癌烟酒人群，只记医生安排）。

## 数据与能力边界

- 患者数据必须存入用户明确选择的资料目录；导入文件在本机处理，识别字段先作为候选内容展示，用户核对后才写入病情记录。
- 2026 临床试验资料包按家族统一方法学采集（资料包在样板癌种链路确认后补充）；登记不证明有效、安全或开放入组。
- 临床试验搜索结果是查找线索，不代表符合入组条件；试验状态和入排标准应向研究中心核实。
- 工作台不提供诊断、分期判读、疗效评价或处置建议；用户看法与担心按"一条信息"记录，标注"不是医生结论"。
- 原型中全部数据为虚构演示数据，不是真实病例。

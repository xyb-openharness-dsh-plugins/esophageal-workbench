# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：食管鳞癌与食管胃结合部腺癌患者及照护者

场景：吞咽困难程度变化影响治疗选择；支架/鼻饲/造瘘等进食通路决策与记录；根治性放化疗后免疫巩固随访；吻合口狭窄扩张与营养管理

核心流程：
1. 选择本机资料目录并导入病理/影像/检验报告
2. 核对候选信息，建立分段病理与分期档案
3. 记录吞咽分级与进食通路变化
4. 按疗程整理放化疗与免疫治疗记录
5. 生成复诊与营养随访准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：分段与病理档案、吞咽分级序列、进食通路记录、体重与白蛋白趋势、放化疗疗程与复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first

## 用户新增确认（2026-10-18）

- 与结直肠癌、胃癌、宫颈癌三个新癌种同批启动，「样板先行+批量」：食管癌本轮只到 SPEC 草案。
- 差异化力度定为「中等：共享骨架+专属模块」；不得把同一套分类换名字复用。
- 食管癌专属主线定为「吞咽分级与进食通路 + 根治性放化疗路径」；营养模块为四癌种中权重最高（营养不良负担最重）。
- 品牌：无专属 Logo，先走长春花蓝（periwinkle）色系+文字标识（EsopPal 小咽宝，占位名）。
- 参照物同结直肠癌条目。

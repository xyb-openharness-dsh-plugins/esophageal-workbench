# SPEC · 小咽宝 EsopPal 食管癌工作台 v0.1

日期：2026-10-18。状态：**草案，等待 G1/G2 审**。样板链路（结直肠癌）确认后复用其工程骨架。

## 0. 三道闸口

同结直肠癌 SPEC §0。本轮只交付 SPEC 草案。

## 1. 目标与非目标

**目标**：让食管鳞癌/食管胃结合部腺癌患者（及照护者）回答五个问题：

1. 我的病理类型（鳞/腺）和部位分段是什么？为什么决定了"手术还是放化疗"？（**路径**）
2. 现在吞咽到什么程度？靠什么进食？（**吞咽与通路**）
3. 治疗走到哪一步：术前新辅助 / 根治性放化疗+免疫巩固 / 术后辅助？（**疗程**）
4. 体重和白蛋白趋势如何？（**营养趋势**，四癌种中权重最高）
5. 下次门诊带什么问什么？（**就诊准备**）

**非目标**：不做诊断、不做吞咽功能判定、不推荐支架/造瘘选择、不做营养处方、不做病友社区。

## 2. 产品立场

继承家族 9 条立场（结直肠癌 SPEC §2），食管癌补充：

10. **吞咽分级是自查记录**：分级由内镜/影像评估与医生给；用户自查序列固定标注"自查，不是医生评估"。
11. **进食通路不替选**：支架/鼻饲/造瘘的选择记录"医生建议原话+患者实际在用"，不给利弊排序。

## 3. 范围（一期）

| 模块 | 内容 | 差异点 |
| --- | --- | --- |
| 看板 | 定调条 → **病程状态卡（36 号 §2.6，通用骨架首卡）** →「现在可以做」→ **吞咽与进食状态卡（本癌种业务首卡）** → 体重/白蛋白卡 → 接下来/最近变化 | 吞咽卡为本癌种业务首卡；病程状态卡压在它之上，理由见下 |
| 我的分型 | **病理类型（鳞/腺，分开建档）**、**部位分段（颈/胸上/胸中/胸下/EGJ，EGJ 含 Siewert 分型记录位）**、分期（TNM）、会诊 | 类型与分段双主键 |
| 治疗历程 | **治疗路径三选一结构（手术路径 / 根治性放化疗路径 / 系统治疗）**、新辅助疗程、放化疗剂量疗程记录、**免疫巩固期记录**、手术与吻合口记录 | 路径结构是本癌种核心 |
| **吞咽与进食通路（专属一级模块）** | 吞咽自查序列（能吃：普食/软食/半流/流食/水呛/完全梗阻）、进食通路档案（经口/支架/鼻饲/胃造瘘/空肠造瘘，起止日期）、扩张记录（日期+次数）、误吸/呛咳事件 | 食管癌独有 |
| 检查与指标 | 体重、白蛋白、血常规、**SCC-Ag（鳞癌）**、影像（食管造影/CT）、胃镜 | 白蛋白升主位 |
| 病情一图秀 | 治疗节点 + **体重与白蛋白双序列** + 吞咽自查序列（分类节点不画折线） | 双序列结构 |
| 营养支持 | 进食量与体重 / 当前困扰（与吞咽模块联动，但记录视角不同：一个是"怎么吃进去"，一个是"吃了多少"） | 保留独立页（四癌种中唯一双营养入口，理由：负担最重） |
| 心理支持 | 当下感受 / 进食社交与形象 / 生育与家庭 | 骨架+专属子页 |
| 复诊准备 | 复诊节奏 / **胃镜+影像随访节点** / 第二原发监测提醒记录（头颈/肺，仅记录医生安排）/ 就诊准备 | 鳞癌特有监测位 |
| 临床研究 | 2026 线索 / 已收藏 / 入组问题 | 骨架 |
| 设置 | 同骨架 | 骨架 |

**为什么病程状态卡压在吞咽卡之上**（2026-10-27，36 号 §2.6 落地时定）：

- 两张卡回答的不是同一个问题。病程状态卡答「我现在处在病程的第几天、下一步谁排的」——这是**全家族通用**的位置感；吞咽卡答「今天能吃什么」——这是**食管癌独有**的业务重点。
- 位置感先于业务重点：一进工作台先要能定位「我在哪」，再决定今天记什么。所以通用骨架首卡在上，业务首卡在下。
- 原来的琥珀色「下一次节点」提示条并入病程状态卡的现状行（同一句话只出现一次），那条 `.alert-strip` 不再渲染。

### 明确不做

支架品牌推荐、扩张时机建议、瘘的分诊、"能不能手术"判断、营养液品牌推荐、病友匹配。

## 4. 信息架构（10 个一级页）

```
看板
我的分型 ── 病理与分段 / 分期 / 会诊
治疗历程 ── 治疗路径 / 新辅助与放化疗 / 免疫巩固 / 手术与吻合口
吞咽与进食通路 ── 吞咽自查 / 通路档案 / 扩张与事件
检查与指标 ── 体重与白蛋白 / SCC-Ag / 影像与胃镜
病情一图秀（体重+白蛋白双序列）
营养支持
心理支持
复诊准备 ── 复诊节奏 / 胃镜影像随访 / 就诊准备
临床研究
```

差异自查：独有「吞咽与进食通路」；治疗历程以"路径三选一"开局，与其它癌种的"线"结构不同；一图秀是双序列。

## 5. 特有场景

| # | 场景 | 给什么 | 不给什么 |
| --- | --- | --- | --- |
| E1 | 确诊后"手术还是放化疗"沟通 | 路径结构+医生原话留痕 | 不替患者比较优劣 |

## 7. 风险

双营养入口困惑 → 两页各写一句职责边界；自查序列被当诊断 → 固定标注；路径结构过复杂 → demo 里用一句话解释+图示。

## 8. 术语

dCRT：根治性同步放化疗（不手术）；EGJ/Siewert：食管胃结合部及分型；免疫巩固：放化疗后免疫治疗维持阶段；第二原发：新的原发肿瘤（鳞癌烟酒人群需监测头颈/肺）。
